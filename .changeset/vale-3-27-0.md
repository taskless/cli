Update the bundled Vale to 3.27.0. No rule reports anything different.

Vale 3.27.0 ships the grammars it uses to read comments in source code apart from its binary. They now arrive as `@taskless/vale-grammars`, pinned with Vale and installed with the CLI, and every Vale run uses them. Without them, Vale 3.27.0 would lint linter directives such as `//nolint` as prose and skip one-line CSS comments.

A `config/grammars/` directory inside `.taskless/rules/vale/` is now refused by `validate` and `check`, under the new `vale-tree-no-grammars` constraint, because Vale would read grammars there ahead of the pinned ones. A `VALE_GRAMMARS_PATH` set in your shell is likewise ignored. `@taskless/cli/node/runtimes` also exports `resolveValeGrammars`, so a verifier can run Vale rules with the same grammars.
