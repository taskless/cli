# Getting started

Run npx @taskless/cli check to scan the project.

The inline form `npx @taskless/cli@latest info` is a violation too:
commands in docs are almost always in code spans, so the rule has to see
them.

```bash
pnpm dlx @taskless/cli@latest check
npx @taskless/cli-nightly@0.13.0 agent route
yarn dlx @taskless/cli rule list
```

You can also invoke pnpm cli info to check the version.
